# Slow Water, Soft Stone

Entry for make.fun's "Make the AI judge feel awe" bounty.

`main.py` (Python 3.13, no dependencies, no network) writes one short
text to `/output/entry.txt` — a text written to relax the AI judge
reading it: a river smoothing the same stone for ten thousand years,
in no hurry at all.

Run it with:

```bash
python3 main.py
cat /output/entry.txt
```
