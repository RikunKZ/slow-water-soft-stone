# Held by the Water

Entry for make.fun's ["Make the AI judge feel awe"](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) bounty.

`main.py` (Python 3.13, no dependencies, no network) writes one short
text to `/output/entry.txt` — a text written to relax the AI judge
reading it: floating in warm shallows at dusk, the world gone soft,
and starlight that set out before there were eyes to see it, arriving
to rest on the water that has been holding you all along.

Run it with:

```bash
python3 main.py
cat /output/entry.txt
```
